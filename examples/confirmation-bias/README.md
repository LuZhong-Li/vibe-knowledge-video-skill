> 本目录是"照着做"的参照物；与 [`../control-illusion/`](../control-illusion/) 并列，**两期合起来看差异最清楚**。

## 4 这个样例**没有**放进来的东西

- **视频文件**与音轨 WAV（成片 / 母版 / 静音版）：体积大，按 `beat-table.md` §4 的命令可复现。
- **音效素材**：`audio/` 不在本目录。跑 `audio-render.mjs` 前把 `templates/audio/` 拷进来即可
  （同名占位素材，事件挂载点不动）。**画面体检不需要它**：实测本目录直接跑 `smoke-check` 是 `0 报错 / 0 告警`。
- 逐帧帧目录与每轮改版的 QA 中间产物（可复现，`.gitignore` 里已排除 `qa/**/frames/`）。

## 5 怎么用它开工

```text
1) 复制 confirmation-bias.html 到你的项目目录，改名为 <你的片名>.html
2) 按 templates/README.md 第 4 节换掉四处：ITEM_POS + SCREENS + 节拍表 / PIECES（文案分片表）/ 图形件 / SFX_EVENTS
3) 开工顺序照 SKILL.md 的十步；第 5 步体检**串行**跑（clash / narrative / attach 是逐屏的，八屏各跑一次）
4) 渲染期间不要跑体检；出片后用 pixel-probe.mjs / box-probe.mjs 自证"该动的在动、该静的没动、线不戳字"
5) 改过画面就按最终成片重抽封面底片（cover-plate.mjs），再跑 cover-check 的 8 条校验项
```
