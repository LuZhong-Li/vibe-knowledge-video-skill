# 封面工程 · 《确认偏误》（「一半」款）

> 方案：**金属字主视觉**（「一半」当视觉锚点 + 标题带 + 副题）—— 与成片 S3 的重音同源，
> 缩略图里仍能一眼认出「一半」。封面**不嵌进视频片头**（会改变时序）。

## 1 文件

```text
cover-0.html              封面源（单文件；版面表在 <script id="coverLayout"> 里）
cover-0-layout.json       渲染时导出的实测版面
cover-0-1920x1080.jpg     成品（q90，交付主图）
cover-0-1920x1080.png     无损版（同一帧的 PNG）
缩略测试-540x960.jpg       抖音竖版缩略尺寸（中心裁切预览）
缩略测试-540x304.jpg       抖音横版缩略尺寸（8 条校验项里量的就是它）
cover-check.json          cover-check.mjs 的完整实测数据
plate-bg.png              从成片抽的背景引擎层（射线 / 光晕 / 粒子 ×0.35 / 颗粒，核心区无粒子）
ref-s3-48.5s.png          抽取底片时的成片原帧（对照用）
assets.json               抽取参数与出处（时间码 / dim / 核心区矩形）
```

## 2 复现（三步）

```powershell
cd templates\tools
# ① 从成片抽底片（无柱体方案用 cover-plate.mjs；有柱体的方案才是 cover-extract.mjs）
node cover-plate.mjs --film <成片.html> --cover <封面.html> --out <本目录> --t 48.5 --dim 0.35
# ② 出图：1920×1080 JPG(q90) + PNG + 两档缩略
node cover-render.mjs --cover <封面.html> --out <本目录> --name cover-0
# ③ 8 条《最终校验项》（量的是**成品 JPG 的像素**，不是源 HTML）
node cover-check.mjs --cover <封面.html> --jpg <本目录>/cover-0-1920x1080.jpg `
                     --thumb <本目录>/缩略测试-540x304.jpg --json <本目录>/cover-check.json
```

本版实测：**8/8 通过**。关键几条 ——「一半」在 540 缩略里仍是第一视觉（墨迹 90×90，高度 ≥ 标题 ×1.4）、
1920 下「一半」是两个完整字形（填充率 0.138，非碎块）、副标题单行 635–1282px、
底部 y>972 的 108px 带最大亮度 0.045（无关键文字）、核心区粒子 0 个、无过曝。

## 3 两个坑（都记在 README §21 里）

1. **底片含程序化颗粒**：每次抽取的图在**噪声层**不同（构图 / 文字 / 金属字材质完全一致），
   所以"重新抽一次底片"后封面文件字节会变，属预期；要逐字节稳定就别重抽。
2. **居中标定是提示项**：`cover-check` 会顺带量"墨迹中心 vs 几何中心"（本版标题墨迹中心 955，cx 960，残差 5px），
   工具建议把版面表 `inkDx` 15→20。这不在 8 条校验项里，是 0.26% 的光学居中小项，本版**未动**。
