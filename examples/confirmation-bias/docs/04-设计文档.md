## 3 分幕网格

### 2b 元素绑定关系（文字跟随）—— 本版新增的硬约定

| 元素 | 是否跟随移动 | 跟随对象 | 实现 |
| --- | --- | --- | --- |
| **立场卡整体（边框 + 卡内符号 + 卡内文字）** | **是（整体退场）** | 卡片 Group | 卡内文字用 `scaleCouple:1` 与卡片同缩放，并带 `outAt/outDur` 与卡片同帧淡出——不会出现"卡片没了文字还在" |
| 证据符号 | 是 | 证据云 | 8 个 `EV_ELS`，位置每帧由 `updateField` 按 `t` 算出 |
| **证据文字标签** | **是** | **所属证据符号** | `updateField` 把符号的**真实位移/缩放**写回 `ITEMS.evN.dx/dy/k`，挂在它身上的 `attachToLabel` 标签自然跟着走 |
| 焦点框（S2） | 是 | 当前扫描证据 | `FOCUS_ORDER` 五个目标间平滑跳转；只改亮度与描边，不带动文字位置 |
| **分组标签「你留下的 / 你忽略的」** | **是** | **左侧 / 右侧那一堆的中心** | 每帧把两队群落的**实测中心**写回 `ITEMS.keepZone / dropZone` 的 `dx/dy` |
| 场景标签（S6） | 是 | 所属场景图标 | 结在 `mainA/B/C` 上，随图标的 4px 浮沉一起动 |
| 节点标签（S5 / S7） | 是 | 所属节点 | 结在 `fnode1-4 / bnode1-4` 上 |
| 主标题 / 金句 / 底部说明 | 否 | 安全区固定 | 只有入场动画，不跟随任何图形 |

**心理桥段的定位**：`既然你确立了立场，大脑就会主动寻找可以支撑它的证据` 是**全局居中的独立文本**
（不挂在任何卡片组上），只当心理旁白；15.0s 起与卡组同时淡出，画布在 16.8s 变干净。
S2 开头的**搜索环**同样是独立图形件（不属于任何证据组），22.5s 前收干净，不与证据抢位。

**两条配套修正**（都是这次绑定检查抓出来的真问题）：

1. `renderPiece` 之前用**静态盒心**采样光照（`rec.cx/cy`）——附着标签一旦位移较大
   （本片 S3 分流 144px），页面算出的明暗就和体检脚本对不上（实测偏差 0.04）。
   现在改为用**标签当前所在位置**采样。
2. S3 的分流由「斜向散点 → 2×2 两堆」改成**只走横向**（每个符号保持自己那一行、只换列）。
   这样任意两条标签的纵向间距在整个分流过程中**恒定**，不会出现"一边横移一边撞在一起"；
   两堆各两列（左 0.395 / 0.470，右 0.545 / 0.625），中间空隙 144px。

绑定体检脚本：`qa/v1/bind.mjs`（逐时刻量「标签盒心 ↔ 所属元素中心」的 Δ）。
判据：**Δ 在整个运动过程中不漂移**（本片实测 S3 全程 Δ 恒定：证据标签 70–79px、分组标签 124–127px，
这两个数是设计偏移——标签贴在符号下方、分组标签贴在群落上方）。

### 2c 引导线终点几何（v3.4 修正，写成硬约定）

`updateLeaders()` 画的是「物品 → 附着标签」那条 1px 暗香槟金线。**终点不得进标签盒**：

1. 基准口径：终点 = 标签左缘中点沿**线段方向**退 16px（这是 v2-c 的原设计）。
2. **修正（v3.4）**：斜向入射时按方向退让主要发生在纵向，点仍在盒内 —— 实测 S1「支持死刑」终点
   `(402,244)` 落在字盒 `x[396..611] y[197..261]` 内 6px，S2/S3 证据标签最深进盒 10px×5px。
   现在：若进盒 **> 4px**，就与「标签盒外扩 6px」求交，把终点落到盒外切点。
3. 两条保险（都是实测撞出来的，别删）：
   - 进盒 **≤4px 不动** —— S7 四条节点引线 `len - 46 = 15.8 < 16`，端点与起点本来就重合（零长、不可见），
     强行收线会退化成孤立小点；
   - 回退后**不足半段不退** —— S2/S3 那批"标签紧贴物品"的引线只有 22–50px，退完只剩 8px 残点，
     比原问题更难看。
4. 复现验收：`node qa/doubao-review/dom.mjs confirmation-bias.html 6,8.6,12,20,26.4,47.4,60,69.07,80,98.4,110,118,132`
   —— 每条引线长度 + 「引线穿字」计数。改动前 S1 每时刻 6 处、S3 3 处；改动后 S1/S5/S6/S7/S8 全 0 处。
5. **图层关系是这条约定的前提**：`#structures`（引线 / 筛网 / 分隔线）z-index **3**，`#texts` z-index **4**
   —— 任何几何重叠最终都被字形盖住。所以"分隔线压字""筛网线穿字"在**像素层不成立**；
   真正会露出来的只有"线的**端点**停在字盒内的空白处"这一类。

### 2d 跨元素读位置：必须自己算当前帧，不能读 `ITEMS.*.dx`

**症状（v3.5 抓出来的真缺陷）**：S1「小球靠近哪一侧，哪一侧卡框呼吸发亮」**从来没生效过** ——
实测球在最左（3.20s）时左右卡框的不透明度都是 `0.847`、描边都是 `3.49px`，两侧完全同亮。

**根因**：`updateItems()` 在**每帧开头**把所有物品的 `dx/dy` 重置
（`it.dx = bobAmp·sin(...)`，selector 的 `bobAmp` 是 0 → 恒为 0），
而 `updateOpinionCards()` 排在 `updateSelector()` **之前**，所以它读到的
`ITEMS.selector.dx` 永远是 0 —— `prox` 对两侧算出同一个值。

**修法**：卡片不再读 `ITEMS.selector.dx`，改为在卡片里用**同一个** `selPos()` 直接算当前帧球位：
`var bx = 0.104 * W * selPos(t - S1.sel0);`

**验收**（`node qa/v1/sel.mjs confirmation-bias.html`）：

| 时刻 | 球位 dx | 左卡 op / 描边 | 右卡 op / 描边 | 结论 |
| --- | --- | --- | --- | --- |
| 3.20s（到左） | −200 | **0.999 / 4.59px** | 0.78 / 3.00px | 偏左亮 ✅ |
| 3.90s（到右） | +200 | 0.78 / 3.00px | **0.89 / 3.80px** | 偏右亮 ✅ |
| 5.30s（到左） | −200 | **0.916 / 3.99px** | 0.78 / 3.00px | 偏左亮 ✅ |
| 6.00s（到右） | +200 | 0.78 / 3.00px | **0.993 / 4.55px** | 偏右亮 ✅ |
| 7.60s 之后（停住） | −60 | 0.83 / 3.36px | 0.83 / 3.36px | 两侧同步呼吸 ✅ |

**通用规矩**：任何 update 函数要拿**别的元素当前帧**的位置/亮度/透明度，
要么自己算（推荐，像这里一样复用同一个纯函数），要么确认自己排在那个元素之后。
`updateItems()` 的"先清零再写"是这套引擎的既定顺序，读 `ITEMS.*` 之前先想一遍它在不在这一帧被重置过。

## 9 背景肌理（图生图）的边界 —— 拍板于 2026-10-10

**允许**：背景肌理可以用图生图做（火山方舟 `doubao-seedream-5-0-pro-260628` 等）。
可参与重绘的只有这几样：

- 背景黑灰层次
- 微弱网格
- 暗金颗粒
- 轻微噪点
- 背景光晕

**不允许**（写死，不得越界）：

- 观点卡片　- 证据 SVG 符号　- 文字　- 光球　- 筛网　- 分组标签
- **所有动画关键帧**

**落地口径（与第二期《幸存者偏差》一致的三条）**：

1. **默认关闭**：只有 URL 带 `?ai=1` 时才加载肌理底片（`plates.json` 里按幕登记），
   默认交付版一个字节都不变 —— 保证成片可复现（`node tools/render.mjs --query ai=1` 才是 AI 对照版）。
2. **只换背景层**：肌理底片走 `#aiLayer`（`<img>`，默认 `display:none`）。
   **层级（v3.5 修正后）**：`#bg` 0 → `#grain` 1 → **`#aiLayer` 2** → `#structures` 3 → `#texts` 4。
   原先 `#aiLayer` 没写 z-index，会被 `z-index:0` 的 `#bg` 整个盖住（底片根本显示不出来），
   现已给 `z-index:2` —— 压在底与颗粒之上、叙事图形与文字之下，**物理上不可能遮住符号或文字**，
   也不动任何元素的坐标、父子级、关键帧。
   登记表是页面里的 `AI_PLATE`（当前只有 `S8: qa/ai/frames-s8-norm/`，底片尚未生成 →
   `?ai=1` 现在只会显示空层，交付默认版一个字节都不变）。
3. **校色归一**：底片按 `plates.json` 里登记的灰度/明度/对比参数归一化后再用，
   避免"背景亮度一变、文字对比度跟着掉"（可读性由 `tools/readability-check.mjs` 复核）。

> 一句话：**仅背景肌理参与图生图重绘，所有叙事图形、文字、动画位置与父子级关系保持不变。**
