### 4.0 文字跟随元素：绑定写在哪一行

**v3.2 新增：立场卡整体退场 + 心理桥段 + S2 搜索环**

```js
/* ① 两张观点卡 13.2–15.0s 整体收缩淡出：卡、卡内符号、卡内文字一起走

     低动态窗从 10.2s 压到 4.2s；改这一幕时刻必须同步检查 LIGHT_ANCHORS 与音效事件表） */
var ex = smoothstep(clamp01((t - S1.cardsOut) / S1.cardsDur));   // 0 → 1
it.dx = Math.round(side * 70 * ex);      // 向两侧轻微收拢

// 卡内文字用 scaleCouple:1 → 标签缩放 = 物品缩放，与卡片同生同灭

```

配套：`outAt/outDur` 让任意文字片按自己的时刻淡出（默认仍是幕尾淡出）；
`sp.outLead` 让物品按自己的时长淡出（观点卡 1.8s）；幕内字幕/角标改为**提前 0.3s 交叉淡化**，
避免换幕切点出现"两屏都还没亮"的空帧。

**v3.3：采纳豆包 v4 的两条文案 + 视觉微调（其余退回）**

```js
/* 命名仪式铺垫（S3 尾）与反问钩子（S4 尾）——都放在左侧空列，避开底部带 */
{ s:2, t:'这种偏差，心理学上叫——',     x:rx(0.05), y:ry(0.660), start:S3.name }
{ s:3, t:'你可能会想，这是故意的吧？', x:rx(0.05), y:ry(0.805), start:S4.hook }

/* 事件表按时间升序：体检脚本按数组顺序算同类最小间隔，尾部追加会算出负间隔 */
SFX_EVENTS.sort(function(a, b){ return a.t - b.t; });
```

三条硬约束在采纳时被守住：
① 重音仍是 **3 处**（47.4 / 67.5 / 129.2）——心理桥段入场从 `low_impact` 改成 `sub_rise`；
② 转场音只用 `audio/` 里**真实存在**的素材（豆包方案里的 `riser` / `whoosh` 没有对应文件，
   浏览器会静默丢弃、混音脚本会直接崩）；
③ 两条新文案不进底部窄带（A30 对 y≥0.86H 的总宽有上限），也不与「一半」的注、文献线索、
   「示意：仅概念模型」重叠。

文字不做独立的一层全局动画 —— **每个标签都结在它所属的元素上**，元素动，标签跟着动：

```js
/* 证据符号：每帧把真实位移/缩放写回 item —— 挂在它身上的标签随之走 */
var ei  = EV_ITEMS.indexOf(d);
var itv = ITEMS['ev' + (ei + 1)];
itv.dx = Math.round(px - itv.cx);
itv.dy = Math.round(py - itv.cy);
itv.k  = 1 + (Math.min(sc, 1.14) - 1) * 0.35;

/* 分组标签：每帧把两队群落的实测中心写回 keepZone / dropZone */
kz.dx = Math.round(gL.x / gL.n - kz.cx);   // 「你留下的」跟着左堆
dz.dx = Math.round(gR.x / gR.n - dz.cx);   // 「你忽略的」跟着右堆

/* 光照采样：必须用标签当前所在位置，不能用静态盒心 */
var own = litFactor(rec.cx + dx, rec.cy + dy, L);
```

配套约束：**分流只走横向**（每个符号保持自己那一行、只换列），这样任意两条标签的纵向间距
在整个分流过程中恒定，不会出现两条标签一边横移一边撞在一起。列分配用全枚举取
「最大位移最小」的解：左两列 `[0.395, 0.470]`、右两列 `[0.545, 0.625]`，
实测 `maxTravel 144px / maxSpeed 11.0px/s`。

| 幕 | 关键实现 |
| --- | --- |
| S1 | `updateOpinionCards` 用小球位移算 `prox = 1 - |bx - sideA| / 0.15W`，再乘 2.6s 呼吸波 → 边框亮度/粗细/发光与卡内符号状态；`updateSelector` 用 `sin(u·4π)` 往返两回合，6.6s 才出发（文字在前） |
