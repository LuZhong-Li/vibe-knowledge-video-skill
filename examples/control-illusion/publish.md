## 2 评论区（大众通俗易懂版本，可拆 2–3 条）

```text
① 心理学家 Langer 在 1975 年做过一个彩票实验：
   一组人自己挑号码，另一组人拿随机分配好的号码。
   两种彩票的中奖概率完全相同，但被问到愿意卖多少钱时，
   自己挑号那组开出的价格，平均高出 4 倍。
② 也就是说：亲手选择，改变不了概率，只改变你对概率的感受。
   大脑会给「我选的」这件事加一层补偿——
   不确定的事情一旦经过自己的手，就变得像是可控的。
③ 所以下次当你觉得「这球一定进」「这支一定涨」的时候，
   可以先问自己一句：这是我真的能掌控，还是因为这是我选的？
```

## 4 为什么这样发

| 选择 | 理由 |
| --- | --- |
| 标题只给核心结论，不做悬念标题党 | 知识类内容的完播依赖「我大概知道要讲什么，但想知道为什么」 |
| 正文只有一句话 | 抖音正文区在播放页只露前一行；把解释塞这里等于没写 |
| 解释放评论区并置顶 | 想看的人能看到细节，不想看的人不被挡；评论区还能承接追问 |
| 置顶提问指向具体体验 | 「这球一定进」是大多数人有过的瞬间，比「你怎么看控制错觉」更容易被回答 |
| 上传带音效版、不叠加平台音乐 | 平台的背景音乐轨道会盖住事件拟声，而音效与画面是同一批时间码 |
| 封面不嵌进视频 | 会改变视频时序、破坏音画对齐（坑 6）；封面只是列表页的缩略图 |
