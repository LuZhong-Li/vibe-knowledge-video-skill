# 样例工程 · 《控制错觉》

> 这是一次真实交付的完整工程：**Vibe 知识大赏风格 / 16:9 / 1920×1080 / 30fps / 无人声** 的认知科普短片。
> 上传主片：`123.500s / 3705 帧 / −25.5 LUFS / 真峰 −0.5 dBTP`（未剪版 128.000s）。
> 本目录是"照着做"的参照物：**新项目先看这里的结构与数字，再决定自己哪里不同。**

## 4 这个样例**没有**放进来的东西

- **视频文件**（成片 / 母版 / 手机预览）与音轨 WAV：体积大，按 `docs/` 里的渲染命令可复现。
- 每次改版的 QA 中间产物（七屏 x 十几个版本的静帧、逐帧截图目录）。
- 授权音效原文件：仓库里 `templates/audio/` 是程序化生成的**占位素材**，
  正式交付时按 `docs/02-...md` §6.6 的检索词换成授权采样即可（同名覆盖，事件挂载点不动）。

## 5 怎么用它开工

```text
1) 复制 control-illusion.html 到你的项目目录，改名为 <你的片名>.html
2) 按 templates/README.md 第 4 节换掉四处：ITEM_POS+SCREENS+节拍表 / PIECES / 图形件 / SFX_EVENTS
3) 跑 templates/tools 里的体检（smoke → film → clash → narrative → attach → keyword → aspect）
4) 逐帧渲染 + 合成 + 合音轨，最后按 docs/02-...md §13.9 的方式做剪短与电平
```
