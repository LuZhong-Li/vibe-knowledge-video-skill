**剪短版（123.5s，上传主片）的映射**：`t < 113.7` 不变；`t ≥ 118.2` 前移 4.5s。
因此重音②仍为 51.7s、重音③变为 **120.5s**；事件从 30 条降为 **29 条**
（原 114.0s 的 `swish_soft` 随剪切段一并去掉）。垫音**从文件 0 处连续取 123.5s**，
不做时间轴硬剪 —— 53.8Hz 长音天然连续，不存在呼吸断点。

## 4 逐屏音效挂载的原则（不是随便配的）

| 图形事件 | 音效 | 音量 |
| --- | --- | --- |
| 线条 / 轮廓生长、转场 | `swish_soft` | −17…−20dB |
| 文字与标签淡入 | `soft_tick` | −21…−22dB |
| 球体脉动 / 光点 / 小球堆叠 | `pulse_tap` | −21dB |
| 概念展开、轮廓描边铺垫 | `sub_rise` | −22dB 级 |
| **核心结论节点（全片仅 3 处）** | `low_impact` | **−12dB** |

音效**只挂在图形事件上**，不挂文字弹出事件；同一时刻最多 2 个；
同类事件有最小间隔（tick 0.18s / swish 0.35s / impact 1.5s）。
