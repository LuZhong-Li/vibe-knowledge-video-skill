## P0.6 视觉完成度落地要点（v2.3 实测教训）

1. **金属渐变字必须做亮度验收**（A10）。第一次实现时它比旁边的白字还暗，
   原因是 `background-clip:text` 的元素上写了 `text-shadow`——阴影画在渐变之上，
   把字压暗约 45%。这条已升格为 P0 约束⑤，后续任何金色关键词都按此检查。
2. **文字位移取整**（P0 约束⑥），否则字形发虚、渐变亮部被抹平。
3. 圆环层级必须是"球在字上"（z-index 6 > 4），并逐屏校验 A11。
4. 每屏扩展背景弱结构时，射线/曲线的透明度上限不得突破（射线 ≤.055、曲线 ≤.22），
   否则会变成"科技感 HUD"，违反 §4.5 禁止清单。
5. 背景结构随正文"生长"（曲线 2.2s 长出来），这是"事件感"的来源，
   不是静态贴图；新增背景元素一律要有 `t` 驱动的缓慢变化。

## P0.5 待你确认后要做的事（分片系统落地）

1. 把 `shot-01.html` 里的分片引擎抽成骨架（`piece(t)` 纯函数 + 布局表数据结构），
   七屏共用同一套：布局表写坐标，引擎负责入场、悬浮、呼吸。
2. 给每屏写**逐片布局表**，并逐片跑 `levels.mjs` 确认 0 越界（分片越多越容易顶边）。
3. 版式轮换按 §5.2 执行：相邻两屏版式不得相同，S1 用"阶梯向右"，
   S2 用"上下夹击"，S4 用"数字居中 + 说明左对齐"。
4. 呼吸 / 弹入按 §6.2 **定稿参数**落地（soft），`motion-demo.html` 的 strong 仅留档。
5. 主球规格（220px / 描边 .55 / 球内号码 / 对角平衡）作为母题组件参数，
   S1 之后 S3 的球阵列、S5 的球图标都从同一组件取值，不允许各写一套。
6. 全局把硬编码金色字面量替换为 `--gold` / `--gold-dim` 两个 token。

## P1 骨架要固化的东西

1. **token 层**：颜色、字号、安全区、动效常量集中在 CSS 变量 + 一个 `SPEC` 对象里，
   后续任何调整只改一处。
2. **时间轴引擎**：`render(t)` 纯函数式，所有状态由 `t` 推导（v1 已验证此模式可用，
   且支持逐帧复现，是能稳定出片的前提）。
3. **母题组件**：`lotteryBall(d)` / `probScale()` / `particles()` 三个可复用构造器，
   保证 S1/S3/S5 的球是"同一个东西"。
4. **文字引擎**：行级出场时间自动排布 + L0/L1 不转暗规则 + 段落转暗。
5. **量测钩子**：给每个文字块打 `data-lv`（级别）标记，供 `levels.mjs` 自动统计层级比。

## P2 逐屏实现顺序

S2 → S4（两个爆点页，风险最高，先做）
→ S3 → S5（母题复用，验证统一性）
→ S6 → S7（图形与收束）
→ S1 回填（已是样图，接上时间轴即可）

每屏完成即出样图并跑一次几何体检，避免最后一起返工。

## P3 会新写的脚本

| 脚本 | 作用 | 为什么必须有 |
| --- | --- | --- |
| `tools/levels.mjs` | 自动输出每屏「最大字号 / 注释字号」层级比表 | 你关心的核心指标，不能靠肉眼估 |
| `tools/coverage.mjs` | 逐句比对原稿 33 句是否 100% 出现在页面 | 防止"改设计把文案改丢了" |
| 现有 `check.mjs` / `timeline.mjs` / `selftest.mjs` | 越界、空场、停放、报错 | v1 已验证可用，直接复用 |

## P4 出片参数（沿用 v1 已验证的链路）

- 逐帧渲染：1080×1920 / 30fps / 4500 帧（分片并行已测：GPU 单实例最快）
- 编码：`libx264 -preset medium -crf 23 -pix_fmt yuv420p -color_range tv`
  （**必须做 full→limited 转换**，否则手机播放黑位发灰；v1 已踩过这个坑）
- 预期体积：100–160MB（v1 实测 114.6MB）

## 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| S2 17 秒要塞 4 句 + 一个爆点 | 读不完 | 前 3 句压到各 3s 出场节奏，爆点在 13s 出现后独占 4s；不够就把 S2 延到 19s，从 S6 借 2s |
| S4「4×」300px 加线框 | 框与安全区冲突 | 300px 定为上限，框内 padding ≥60px；若越界先降到 260px 并记录 |
| S5 三栏文字换行断词 | 观感掉档 | 三栏等宽 + `word-break:keep-all`，超长句整体缩小到 52px；**不改文案** |
| S6 大脑轮廓偏简笔 | 不够"脑" | 先按 1.5px 几何线稿交付；若你要更写实，P2 阶段换 SVG path（不影响其他屏） |
| 目标设备缺思源宋体 | 字形变化 | 字体栈回退到宋体/SimSun；样图与成片在同一台机器渲染，所见即所得 |
| 150 秒塞七屏 | 停顿不足 | 已按"读速 ≥2.2s/行 + 1.2s 段落间隔"核算，A2/A4 验收会兜住 |

## 明确不做的事

- 不改一句文案、不改 150 秒总时长
- 不加配音、字幕条、转场特效、背景音乐（BGM 由你在剪映里配）
- 不引入任何外部资源与依赖
- 不为了好看牺牲可读性（正文任何情况下不低于 52px）
