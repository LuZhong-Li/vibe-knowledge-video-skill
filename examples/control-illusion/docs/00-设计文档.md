# v2 设计文档 · 控制错觉（A+B：纪录片质感 + 彩票/概率可视化母题）

版本：v2.0 草案（待第一镜样图确认）
范围：只换设计系统。**文案一句不动、总时长 150 秒不动。**

---

## 1. 目标与约束

**目标**：把"黑底文案展示页"变成"有设计层级的知识视觉页"。
观众在无声环境下（无旁白、无字幕条）靠眼睛读完整支片子，并且每一刻都清楚该看哪。

**硬约束**

| 项 | 值 |
| --- | --- |
| 画布 | 1080 × 1920（9:16），等比缩放置中，非 9:16 窗口留黑边 |
| 总时长 | 150.000 秒，打开自动播一遍，播完停在最后一屏，不循环 |
| 声音 | 无音频、无旁白、无字幕条；页面文字即全部信息 |
| 依赖 | 单文件 HTML+CSS+JS；零外部资源（无 CDN / 无字体文件 / 无图片 / 无 emoji 图标） |
| 时间轴 | 所有画面由 `t`（秒）计算，禁用 CSS transition/animation 驱动画面 |
| 调试接口 | `window.__seek(t)`、`?t=45`、`?rate=0.5`、`?autoplay=0`、`?debug=1` |
| 交互 | `cursor:none`，全程无需操作即可播完 |

---

## 2. 设计原则（三条，按优先级）

1. **每屏只有一个视觉中心。** 判断标准是字号或对比度上的"压倒性"，
   而不是"这个也挺醒目"。其余元素一律退到支援位。
2. **母题固定，不复用装饰。** 全片只用三个母题（彩票球 / 概率刻度 / 随机粒子），
   靠同一母题在不同屏里承担不同角色来产生"专题感"，而不是每屏换花样。
3. **节奏靠手段交替，不靠字号一路加粗。** 七屏分别用
   字号 / 暗金 / 左右对比 / 数据框 / 三栏图标 / 图形底纹 / 关键词 来制造重心，
   相邻两屏的视觉手段必须不同。

## 3. 视觉系统

### 3.1 色彩 token

| Token | 值 | 用途 |
| --- | --- | --- |
| `--bg-deep` | `#0A0A0A` | 背景基色（近黑，向深炭灰 `#141210` 渐变） |
| `--ink` | `#F5F1E8` | 暖白主文字 |
| `--ink-2` | `rgba(245,241,232,.62)` | 次级文字 / 引导句 / 正文 |
| `--ink-3` | `rgba(245,241,232,.30)` | 注释 / 顶部标识 |
| `--gold-hi` | `#D7B979` | 香槟金高光（金属字上端） |
| `--gold` | `#B8944A` | 暗金主色（金属字下端 / 母题描边） |
| `--gold-line` | `#8A7655` | 暗金灰：辅助线、概率曲线、刻度 |
| `--glow` | `#6B4A1A` | 棕金光晕（透明度 ≤ .09） |

> 色彩层次至少要有四级：**深黑背景 → 暖白文字 → 香槟金关键词 → 暗金灰结构线**，
> 再叠棕金光晕与少量金粒子。只靠黑 + 白 + 一个金色，就是 v2.2 之前"像加了个圆环的黑底页"的原因。

金色关键词全片 **5 处**（原 v2.2 的 4 处作废）：S1「奇怪的事」、S2「控制错觉」、
S4 `4×`、S6「虚假的」、S7「掌控感」。其余屏的颜色重心靠**金/灰对比**与图形，不再加金。

> 代码里只用上面 6 个 token，不允许再出现硬编码的颜色字面量（早期版本的
> `#c2a97c` / `#b8a06a` 全部作废）。

### 3.2 字体

```
"Source Han Serif SC","Noto Serif SC","Songti SC","STSong","SimSun","Times New Roman",serif
```

数字与 `×` 用同族衬线数字。正文禁止使用无衬线做正文（仅图标标签可用）。

### 3.3 四级文字层级（1080 宽画布绝对字号）

| 级别 | 角色 | 字号 | 行高 | 字重 | 颜色 | 用量限制 |
| --- | --- | --- | --- | --- | --- | --- |
| L0 | 爆点（数字 / 关键词） | **160 / 300px** | 1.10 | 600 | 暗金或暖白 | 每屏 ≤1 处 |
| L1 | 大标题 / 金句 | 72–88px | 1.40 | 600 | 暖白 | 每屏 ≤1 处 |
| L2 | 强调句 | 60–64px | 1.60 | 500 | 暖白 | 每屏 ≤2 行 |
| L3 | 解释句 | 52–56px | 1.75 | 400 | 暖白 / `--ink-2` | **同屏 ≤3 行** |
| L4 | 注释 | 28px，字距 .10em | 1.60 | 400 | `--ink-3` | 每屏 1 条，贴底部 |

- **正文下限 52px**（手机上约 19px 等效），注释下限 28px。
- 超出的内容不靠缩字号解决，靠"旧段落转暗"腾出注意力。

### 3.4 安全区与网格

左右各 122px，顶部 108px，底部 190px。任何文字、图形不得越界，不允许半个字被切。
正文块最大宽度 836px（1080 − 122×2）。
垂直方向优先"上重心"：内容块中心落在画布高度的 42%–48%。

## 4. 视觉母题规范（全片只用这三个）

### 4.1 彩票球

- 形态：正圆，`1.5px` 描边，内部 8% 同色径向填充；可带一条细弧作高光。
- 直径 90–240px；同一画面内大小必有差异（避免"贴图感"）。
- **主球规格（S1 定稿）**：直径 **220px**，描边 `1.5px` `rgba(184,160,106,.55)`；
  球内放一个号码（如 `7`），字号约球径的 44%（96px），颜色用暖白 `rgba(242,241,237,.55)`
  ——**金色只留给描边**，不占用"金色文字 ≤4 处"的配额。
- **对角平衡规则**：文字重心在左下时，主球放右上；文字居中时，主球放上三分之一。
  目的是让画面呈对角受力，而不是文字全挤在左侧、右上留空。
- 运动：漂浮周期 > 20 秒；自转 ≤ 5°/s；禁止弹性与快速位移。
- 出场位置（同一母题承担三种角色，这是"统一"的关键）：

| 屏 | 角色 | 表现 |
| --- | --- | --- |
| S1 | 氛围 | 两颗漂浮球（一大金、一小冷白），不与文字重叠 |
| S3 | 证据 | 左右各一组 3×3 球阵列，**左组一颗实心金**，右组全空心 |
| S5 | 图标 | 缩小为"打球"案例的线描图标 |

### 4.2 概率刻度

- 形态：1px 主线 + 每 10% 一根 4px 短刻度 + 一个 8px 实心游标点。
- 语义：**等长 = 概率相同**。S2 用单条（两端标 `50%`，游标居中）；
  S4 用上下两条等长刻度对照（概率一样长、标价点不一样大）。

### 4.3 随机粒子

- 60–80 个，直径 1–3px，两层视差（近层更亮更大），缓慢上浮。
- 常驻全片，透明度始终 ≤ 0.15。它是"空气"，不是装饰，任何时刻不得抢字。

### 4.4 结构元素（辅助，不构成母题）

1px 细线 / 1px 细线框 / 极弱径向光晕（≤6%）/ 胶片颗粒（≤5%，12 次/秒跳变）/
S6 专用大脑轮廓（1.5px 线，透明度 ≤0.10，内含 3 个 6–8 秒周期的呼吸光点）。

### 4.5 禁止清单

霓虹色、发光描边、玻璃拟态、科技感 HUD/网格、大色块渐变、弹跳回弹、打字机、
故障闪烁、粒子爆炸、位移 >40px 的转场、emoji 图标、真实照片、3D 渲染、
金色文字超过 4 处、同一屏出现两个同级视觉中心。

### 4.6 分片排版系统（v2.1 新增）

一屏不再用一个 `<p>` 承载整句，而是拆成若干**文本分片**：每片独立定位、独立入场，
位置带轻微错位，形成"分片入场 / 错位悬浮"的节奏。这一节是 4.A 版实现规范。

**分片规则**

| 规则 | 值 |
| --- | --- |
| 分片粒度 | 一个语义片段（短语/短句），通常 3–10 字；一屏 4–8 片 |
| 错位量 | 通用区间 60–80px；**S1 定稿值：标题两片 74px、正文三片 66px**（不做随机散点） |
| 同句内间隔 | 1.1–1.2s（同一句话的分片要连成一句的语气） |
| 句与句间隔 | ≥2.2s |
| 分片入场 | 0.85s：`opacity 0→1` + `translateY 14px→0` + `blur 5px→0` |
| 入场后 | 每片做极慢悬浮漂移（±6px，周期 14s），制造"悬浮"而非"贴纸" |
| 字号 | **绝对 px，禁止 vw/vh/clamp**（原因见 4.7） |
| 字距 | L0/L1 用 `0.04em`；L3/L4 用 `0.08em`（大字距会把长句挤出安全区，见 4.7） |

**分片必须满足的硬条件**：每一片的包围盒都必须落在安全区内，
且**逐片测量**（`tools/levels.mjs` 已支持），不允许只看整块。

### 4.7 实现注意（P0 硬约束 · 六条，不可妥协）

> 这四条是长期约束，不是一次性修补：后续任何一屏、任何一版重做都必须满足。
> 违反 ③ 会让逐帧出片与自动体检整体失效；违反 ① 会让导出视频的版式与设计稿不一致。

**① 禁止 `vw / vh / clamp()` 定字号与坐标。**
`font-size: clamp(28px, 5vw, 88px)` 与 `--x:-42vw` 依赖**浏览器窗口宽度**，
而画布是固定 1080×1920 再整体缩放的：同一个文件在 1280 宽窗口和 1920 宽窗口里，
字号和位置都会变，导出视频的版式就不再是设计的那一版。
→ 一律写 1080×1920 画布坐标下的绝对 px。

**② `pieceIn` 与 `pop` 不能跑在同一个元素上。**
两个 `@keyframes` 都写 `transform`，同属性只有最后一个动画生效，
入场位移会被 `pop` 覆盖（分片会直接"原地放大"，丢掉上浮）。
→ 外层元素做位移入场，内层元素做缩放，各管一个 `transform`。

**③ 关键字动画不能用"自动播放"的 CSS animation。**
页面必须支持 `window.__seek(t)` 与 `?t=45` 精确定位到任意一帧（逐帧出片、
截图体检都依赖它）。`animation: pieceIn 1.4s ease forwards` 由元素插入时刻起算，
无法被 `t` 定位——`?t=45` 会拍到一个动画状态随机的画面，出片必然错帧。
→ 二选一：
  - **推荐**：与现有时间轴一致，所有分片状态由 `t` 计算（`piece(t)` 纯函数）；
  - 或者保留 CSS animation，但必须 `animation-play-state: paused` +
    用负 `animation-delay: -t s` 做定位（可 seek，但每片都要单独设 delay，易错）。

**④ 字距 0.08em 会改变换行，必须重测。**
1080 画布可用宽度 836px，56px 正文一行原本可放 ~15 字，加 0.08em 后降到 ~14 字；
88px 大标题从 ~9.5 字降到 ~9 字。原本刚好一行的句子会变两行，
分片右移后还可能顶出右边界。→ 大字用 0.04em、小字用 0.08em，并逐片复测。

**⑤ `background-clip:text` 的元素禁止使用 `text-shadow`（本片实测踩坑）。**
金属渐变字的字形填充是透明的，而 `text-shadow` 画在**渐变之上**：
实测「边缘暗部」那条 `0 1px 0 rgba(0,0,0,.45)` 把金属字整体压暗约 45%
（关键词区峰值 241 → 215，亮部占比 17% → 2.1%），结果金色关键词比它旁边的白字还暗，
视觉重心直接反转。
→ 阴影一律用 `filter: drop-shadow()`（画在字形之后），需要"边缘暗部"时用
`-webkit-text-stroke: .6px rgba(74,48,12,.28)`，不要用 text-shadow。

**⑥ 文字落点必须取整像素。**
悬浮漂移的位移用 `Math.round()` 取整后再写进 `transform`；亚像素定位会让字形发虚、
金属渐变的亮部被"抹平"，且会显著增加视频码率。实测取整后关键词亮部占比从 2.1% 回到 17%。

**⑦ 循环型动画必须带时间常数断言。**
环绕文字、呼吸、颗粒跳变这类由时间驱动的循环，单位或量级写错就彻底失效，
而几何与亮度体检都抓不到。本片真实踩过一次：转速多除了 60，从 1.8°/s 变成 0.05°/s，动画等于冻住。
→ 组件内部加阈值断言（`if (spin < 0.3) console.warn('[orbit] 转速过低，检查时间常数')`），
并把 `console.warn` 计入自检失败条件（验收 A14）。

### 4.9 金属渐变字规范（金色关键词专用）

| 项 | 规范 |
| --- | --- |
| 渐变 | `linear-gradient(176deg, #FFF6DE 0%, #F4E1B2 20%, #EFDCAF 40%, #FFFBE9 58%, #EBD5A4 78%, #F6E7C0 100%)` |
| 关键点 | 第 58% 处必须有**比暖白更亮**的高光带，保证金属字是画面最亮处 |
| 亮度下限 | 渐变所有色阶灰度 ≥ 200，不允许出现暗金深色档（会把字压成"土金"） |
| 边缘 | `-webkit-text-stroke: .6px rgba(74,48,12,.28)` |
| 光晕 | `filter: drop-shadow(0 8px 30px rgba(107,74,26,.42))`（**不是** text-shadow） |
| 呼吸 | 幅度压到 `0.96 ↔ 1.00`（金属字本身已很亮，幅度大了会显得闪） |
| 验收 | 关键词区亮度峰值必须**高于同屏任何白字**，亮部(>140)占比 ≥ 15% |

### 4.10 背景弱结构（"知识正在发生"的空间感）

背景不能只有颗粒和弱圆环。固定四件（都由 `t` 驱动，全部在文字之下）：

1. **极淡射线**：14 条，从号码球圆心放射，长度 1250±260px，1.4px 宽，
   颜色由 `rgba(215,185,121,.055)` 渐隐到 0，整组 **0.25°/s** 缓慢旋转。
2. **低透明概率曲线**：正态分布曲线，1px，`rgba(138,118,85,.22)`，
   基线 y=1560 / 振幅 190 / σ=210，随正文出现用 2.2s "长出来"；配 8 段刻度。
3. **棕金光晕**：球体后方一团 `rgba(107,74,26,.085)`，半径 820px，呼吸周期 > 30s。
4. **弱暗角**：四角压到 `rgba(0,0,0,.55)`，顶部与底部各留一层线性压暗。

粒子：76 个，其中约 1/4 用香槟金 `rgba(215,185,121,·)`，透明度上限 .17。

### 4.11 圆环参与构图（**方案 A：圆环压住标题右上角**）

- 层级：号码球 `z-index:6`（**在文字之上**），左下小球 `z-index:2`（在文字之下），
  文字分片 `z-index:4`，顶栏 `z-index:3`，颗粒 `1`，背景 `0`。
  早期版本把球放在文字之下，等于"文字压圆环"，不是方案 A。
- 位置：圆心落在标题第二行右侧，圆体与标题右端形成 195px 宽的咬合区；
  校验标准是"**圆环与标题相交、与正文和注释都不相交**"。
- 圆体直径 220px；因自转，元素的包围盒会量到 ~297px，属正常，视觉尺寸以圆体为准。
- 球内号码用暖白，金色只留给描边——不占用金色关键词配额。

### 4.12 新增两个轻动效（可开可关，参数见 §6.2）

- **关键词呼吸**：暗金关键词的透明度做极慢正弦起伏。
- **数字弹入**：数据数字（`4×`）入场时轻微放大，带一次克制回弹。

两者都**只作用于 L0 爆点**，全片合计不超过 6 处；且必须由 `t` 计算（见 4.7 ③）。

## 5. 七屏结构（150 秒）

| 屏 | 类型 | 时间 | 视觉手段 | 视觉中心 | 层级比目标 |
| --- | --- | --- | --- | --- | --- |
| S1 | 大标题页 | 0–9s | 字号 | 钩子句 + 金色彩票球 | 88 / 28 = 3.1× |
| S2 | 关键词爆点页 | 9–26s | 字号 + 暗金 | **控制错觉 160px** | 160 / 28 = **5.7×** |
| S3 | 左右对比页 | 26–48s | 色彩对比 | 左金 / 右灰 球阵列 | 60 / 28 = 2.1× |
| S4 | 强数据页 | 48–62s | 字号 | **4× 300px** | 300 / 28 = **10.7×** |
| S5 | 三案例页 | 62–90s | 三栏结构 | 球 / 骰子 / K线 图标 | 60 / 28 = 2.1× |
| S6 | 认知机制页 | 90–120s | 图形 | 大脑轮廓 + 呼吸光点 | 46 / 28 = 1.6× |
| S7 | 金句页 | 120–150s | 关键词 | 能力 / 运气 / **掌控感** | 72 / 28 = 2.6× |

**验收要求**：S2 与 S4 必须落在 5–10× 区间（"爆点页"的定义）；
其余屏允许 1.6–3.1×，但必须各自有一套明确的非字号重心（对比 / 数据框 / 图形 / 关键词），
且相邻两屏的手段不重复。

### 5.1 逐屏文案与排版

**S1 钩子 0–9s**

- 引导句 52px · `--ink-2`：`你有没有发现`（字距 .16em，降级为暖白小字）
- 标题 96px：`一件`（暖白，`rgba(245,241,232,.86)`）
  + `很奇怪的事。`（**金属渐变字**，香槟金高光带 + 呼吸）
- 正文 52px · `--ink-2`，三片阶梯右移 66px：`同样是彩票，` / `自己选的号码，` / `总感觉更容易中奖。`
- L4 注释：`机选的，心里就觉得不靠谱`
- 圆环：圆心 (836,700)，220px，**压在标题第二行右上角**（方案 A），球内号码 `7` 暖白
- 背景：14 条射线（自球心放射）+ 概率曲线 + 棕金光晕 + 暗角 + 76 粒子（1/4 金）
- 层级比目标：96 / 28 = 3.4×；**金色文字仅 1 处**（`很奇怪的事。`）

**S2 概念 9–26s**（依次淡入，前句转暗）

1. L3 56px：`但从概率上来说，两组号码中奖概率完全一样。`

## 6. 动效规范

### 5.3 文字图形化排版系统（v3.0）

文字不再一律横排成段。每屏保留**一个中心观点**，其余文字降级为注释 / 标签 / 路径文字，
用五种排版方式混排：

| 排版方式 | 用途 | 实现参数 | 已用在哪 |
| --- | --- | --- | --- |
| 超大横排标题 | 钩子 / 爆点 / 金句 | L0 160–300px，金属渐变，`nowrap` | S1 · S2 · S4 · S7 |
| 竖排文字 | 边缘注释、情绪短句 | `writing-mode:vertical-rl` + `text-orientation:upright`，36–38px | S2「概率相同，感受不同」 |
| 斜排文字 | 跟随斜线/情绪解释句 | 引擎 `rot` 参数，`transform-origin:0 0`，角度 −5° | S2「我们会误以为……」 |
| 环绕文字 | 沿圆环/大脑轮廓排列 | 逐字 span 均匀分布在圆周：`translate(-50%,-50%) rotate(a) translateY(-r)` | S2 圆环 17 字纹理 |
| 标签式短句 | 案例关键词、对照标签 | 楷体 36px + 金色圆点，`.tag` 组件 | S2「自己选号 / 机选」 |

**字体分层**（不能乱用）：

| 层级 | 字体 | 用法 |
| --- | --- | --- |
| 主标题 | 衬线 + 金属渐变 | 控制错觉 / 4× / 很奇怪的事 |
| 正文解释 | 思源宋体 / 宋体 | 承载信息的解释句 |
| 标签短句 | 楷体（`--kai`） | 手感来了 / 自己选号 / 机选 |
| 注释小字 | 衬线 28px | 底部说明、百分比 |
| 路径文字 | 衬线 32px · 透明度 ≤ .34 | 沿圆环、曲线排列 |

> **正文一律不用楷体**（可读性会崩），楷体只用于标签、短句、注释。

### 5.4 「降级」不等于「删除」（重要约束）

v3.0 起，规则的准确表述是：**每屏只保留一个中心观点，其余文字降级为注释 / 标签 / 路径文字；
原有的每一句文案必须仍然出现在画面上**（允许拆成多片、允许竖排斜排、允许缩小到注释级）。

原因：本片**没有旁白**。被删掉的句子不是"留给观众想象"，而是永久丢失——观众既听不到也读不到。
按"只留关键词"的方式改，四屏会删掉约 12–15 句、接近原稿 40%，
`A5 文案完整性` 会直接不通过，且「很多事并不受我们掌控」「亲手参与会放大自我影响力」
这两个结论会从片子里消失。

因此**验收标准 A5 不变**：原稿 32 句必须 100% 出现在页面上。
若确实要做"符号叙事"极简版，应作为**独立的第二版**（例如 60 秒短版），而不是替换本片的文案。

### 5.5 物品主体 + 文字跟随互动（v3.5 统一执行规范）

> 一句话：**图形是演员，文字是贴在演员身上的标签。** 不是把文字排得更好看，而是把每一幕
> 改造成"物品在演示概念，文字负责说明它正在做什么"。

#### 5.5.1 每一幕先定义"主角物品"

画面主体是钱卡片（900 / 100）和两个按钮（接受 / 拒绝），卡片平移、浮现、收回，
文字只是贴在卡片旁边的"提议者拿 900""你拿到 100"。

| --- | --- | --- | --- |
| S2 | 圆环、金球簇、灰球簇 | 圆环生长、金球聚拢、灰球弥散 | 标签贴球，解释句拆成注释散在环四周 |

| 类 | 权重 | 形态 | 规则 |
| --- | --- | --- | --- |
| A 主标题 | 最高（但低于图形） | 金属渐变大字号，每屏仅 1 个 | 不拆句；与主图形发生关系（压在环峰值上 / 跟扫光出现） |
| B 附着标签 | 中 | 楷体小字 + 金色圆点，紧贴物品 | **与物品共用一条时间线**：物品位移/缩放/呼吸/明暗，标签逐帧跟随；距离用 rx/ry 固定 |
| C 补充注释 | 最低 | 思源宋体小字，透明度 .46–.62，可斜排/竖排 | 原长句**拆成多条短注释分散**在图形周边，**禁止聚成一个大文本块** |

层级：**图形（最高）＞ 主标题 ＞ 附着标签 ＞ 边角注释**。大面积留白，注释只在图形附近局部出现。

#### 5.5.3 互动逻辑：物品先动，文字才出现

1. 主图形先登场（圆环生长 / 球阵列浮现 / 轮廓描边 / 大数字扫光）
2. 图形开始互动（金球聚拢 / 灰球漂移 / 对比线生长 / 光点脉动）
3. 标签跟随图形出现 —— 图形高亮时标签同步淡入，图形移动时标签保持固定相对距离
4. 补充注释随后**分散、逐段**出现（不在同一时间点全部弹出）
5. 主标题最后锁定画面，触发最重音 `low_impact`

音效仍绑定**图形事件**，不绑定文字弹出事件。

#### 5.5.4 工程实现（`Item` / `AttachmentLabel` / `ScatteredNote` / `LightLink`）

```js
/* 主角物品注册表：图形本体、附着文字定位、光源关键帧三处共用同一组基准坐标 */
var ITEM_POS = { ring:{x:0.50,y:0.42}, gold:{x:0.105,y:0.855}, gray:{x:0.88,y:0.855} };

attachToLabel(item, '自己选号', { ox:0.061, oy:-0.010, start:S2_T.goldTag, fs:rFont(30), tag:true });
/*  ↑ ox/oy = 相对物品中心的固定偏移（rx/ry）；followScale / followAlpha 默认 true */
```

| 组件 | 职责 | 实现 |
| --- | --- | --- |
| `Item` | 物品每帧只更新四个量：微动位移 `dx/dy`、缩放 `k`、光照 `light`、在场权重 `on` | `ITEMS` + `updateItems(t,L)` |
| `AttachmentLabel` | 标签位移 = 物品位移，缩放 = 物品缩放，与物品的相对距离恒定 | `PIECES[].attach` + `renderPiece()` |
| `ScatteredNote` | 原长句拆成的短注释，各自独立 DOM、独立 start，散在图形周边 | 多条 `attachToLabel()`，不带 `tag` |
| `LightLink` | 扫光扫到物品 → 贴在它身上的文字一起亮；物品沉入暗部 → 文字一起压暗 | `lf = (opMin + (opMax−opMin)·f(max(自身光照, 物品光照))) × 物品在场权重`，`opMin/opMax` 默认 0.50↔1.00 |

### 6.1 基础规则

| 项 | 规则 |
| --- | --- |
| 单行出场 | 0.8–1.0s 内完成 `opacity 0→1` + `translateY 18px→0` + `blur 6px→0` |
| 同屏行间隔 | ≥ 2.2s（保证读完）；段落之间额外 +1.2s |
| 旧段转暗 | 新段落出场后，之前的 **L3 解释句**用 1 秒降到 48% |
| 不转暗的元素 | **L0 爆点、L1 大标题永远保持 100%**（v1 的问题是把标题也一起压暗了） |
| 换页 | 旧屏 0.9s 淡出 + 新屏 0.8s 淡入，中间空场 ≤0.6s |
| 母题运动 | 平移 < 12px/s，旋转 < 5°/s，明暗周期 > 5s |
| 首末元素 | 进入本屏后 ≥0.4s 才出第一个元素；最后一个元素在离开前 ≥1.5s 出场完毕 |
| 禁止 | 位移 >40px 转场、弹性曲线、闪烁、任何"突然出现" |

### 6.2 两个轻动效（**已定稿**，只作用于 L0 爆点 / L1 大标题）

| 动效 | 定稿参数 | 备选（本片不用） | 作用于 |
| --- | --- | --- | --- |
| 关键词呼吸 | 周期 **6.0s**，透明度 `0.90 ↔ 1.00` | 4.0s，`0.82 ↔ 1.00` | S2 控制错觉 / S6 虚假的 / S7 掌控感 |
| 数字弹入 | 0.9s：`scale 1.00 → 1.02 → 1.00` | 0.9s：`0.70 → 1.08 → 1.00` | S4 `4×` |

**定稿理由（实测）**：加强版呼吸 0.82 的下限配 4 秒周期，在大号金字上肉眼读作"闪"而非"呼吸"；
加强版弹入 1.08 的过冲在 300px 数字上读作"蹦"，与 §4.5 禁止弹跳回弹、
以及"克制 · 纪录片"的基调冲突。一句话原则：**呼吸要慢，弹入要小。**
备选参数与对比样张保留在 `v2/motion-demo.html`（`?motion=strong`），仅作留档。

- 呼吸与弹入都不改变版式，不产生位移，`__seek(t)` 可精确定位。
- 呼吸可作用于 L0 爆点与 L1 大标题（它是刻意的明暗起伏，**不算 §6.1 的"旧段转暗"**，
  所以与"L0/L1 永远 100%"不冲突）；L3 解释句一律不呼吸。
- 全片带呼吸的关键词 / 标题 ≤3 处，带弹入的数字 ≤1 处；同一个词不做两种动效。
- **推荐版**的用意：`1.08` 的过冲在 300px 数字上会读成"弹一下"，与"克制、纪录片"的
  基调相冲；`1.02` 只让人感到"数字落下来了"。两版都做出来了，可直接对比后定。

**全片施工中新增的两条经验（已并入 §4.7 思路）**

1. 分片是 `nowrap` 时**不会自动换行**，超过 836px 直接顶出安全区；
   改为 `white-space:normal + max-width:836px` 后，必须按「行高 × 行数」重算纵向排布，
   否则相邻分片会互相压住。行高参考：52px→91，60px→93，96px→134，160px→176，300px→330。
2. 个别句子在 84px 下仍会被折断（字体实际字宽略大于 1em）；
   这类"内容宽度贴近 836px 上限"的分片必须显式 `nowrap` 并复测。
