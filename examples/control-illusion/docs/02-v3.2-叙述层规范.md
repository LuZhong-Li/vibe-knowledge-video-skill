## 0 一句话

**图形是叙事本体，文字长在图形上。** 每屏先让图形动起来，文字跟着图形事件逐场浮现；
全片只有**一束正在移动的光**，光走到哪，视线就被带到哪。

## 5 S3–S7 复用步骤（每屏 4 步）

1. **重排该屏 `PIECES[].start`**：按"图形事件 → 文字跟随"的顺序拉开，相邻 ≥0.6s，
   最后一个元素至少在离开该屏前 1.5s 完成出场。
2. **补该屏的 `LIGHT_KEYS` 关键帧**：每个元素出场 +0.6s 的时刻，光要落在它的中心 640px 内。
3. **`UPGRADED[s] = true`**，并给该屏图形写叙事动画（优先复用
   `ringDraw / ringTextS2 / clusterGold / clusterGray`，K 线用"曲线生长"、大脑用"描边生长"）。
4. **跑第 4 节 5 个脚本**，全绿才算该屏过审。

七屏全部置 `true` 后，**一次性整体渲染**（不渲染中间半成品）：

```powershell

node render.mjs --html "..\v2\control-illusion-v2.html" --out <帧目录> --fps 30 --start 0 --end 150 --shards 3 --shard 0
# 编码（full→limited 转换不能省，否则手机播放黑位发灰）
ffmpeg -framerate 30 -i f%05d.jpg -c:v libx264 -preset medium -crf 23 -pix_fmt yuv420p -color_range tv out.mp4
```

## 6 音效规范（v3.2 · S2 已落地）

### 6.1 原则（五条，写死）

1. 全程**没有人声旁白**：音效只做「动作反馈 + 重点强调」，不讲故事。
2. 音量压低：主 BGM **−19.2dB**（= v6/v7 原档的 −18dB 档，见 §6.5）；拟声音效 **−22 ~ −14dB**；爆点重音最高 **−12dB**。
   不能盖过视觉，不能吵。
3. 音效只在**动画事件触发点**播放，不循环、不铺满。
4. 同一时刻**最多 2 个音效**叠加（超出丢弃低优先级；重音 pri=3 优先）。
5. 文案 100% 完整、不删句子；**关掉音效，画面叙事依然完整**（音效是加分层）。

**听觉硬性约束**：无长尾混响（点到即止）、音色统一偏暗金偏暖、杜绝尖锐高频与综艺特效音、
页面初始化即预加载全部素材（触发零延迟）。

### 6.2 工程实现（WAV 采样包 + 事件绑定）

| 环节 | 做法 |
| --- | --- |
| 素材 | `v2/audio/*.wav`：`soft_tick` / `swish_soft` / `low_impact` / `pulse_tap` / `sub_rise`（+`blank` 占位）与 `ambient_pad.mp3`（占位 BGM） |
| 触发 | `SFX_EVENTS` 事件表：时刻全部取自驱动画面的同一批常量（`S2_T` / `RING_S2`）→ **音画同源，不漂移** |
| 调度 | 每帧把未来 **0.3s** 内的事件排队，按精确目标时刻调度；有 `AudioContext` 时走**采样级** `start(when)`，`file://` 下退回媒体元素并做 12ms 起播补偿 |
| 音量 | 事件级 dB（写入事件表）→ `GainNode.gain`；BGM 走 `?bgmvol=-19.2`（默认 −19.2dB） |
| 并发 | 播放前统计仍在发声的实例，≥2 时丢弃低优先级；同类另有最小间隔（`soft_tick` 0.18s、`swish` 0.35s、`impact` 1.5s…） |
| 安全 | 跳转 / 回退 / 静态帧（`?t=`）**一律不触发**；`?sfx=0` 全程静音；缺素材静默降级，绝不 `console.warn` |
| 起播 | 受浏览器自动播放策略限制：默认等第一次交互；`?sfx=1` 主动开启；用 `node tools/serve.mjs` 以 http 打开则走 WebAudio |

> 占位素材由 `node tools/make-foley.mjs --pad 150` 生成（零依赖、纯程序化、统一峰值 −1dBFS、
> 尾部裁到 −60dB 以下；**垫音不含噪声层、<30Hz 已高通**，见 §13.8）。
> **拿到授权库采样后同名覆盖 `v2/audio/` 即可**——事件挂载点、
> 音量基线、并发限制都不用改。

### 6.5 BGM 底层铺垫

- 风格：暗金极简氛围、长音垫、无鼓点、缓慢衰减（`minimal ambient underscore slow no drums`）。
- 音量固定 −19.2dB（**等价于原档 −18dB**）；事件音效在这个基础上叠加；**换页时 BGM 不断**。
- 页面：`?bgm=audio/ambient_pad.mp3&bgmvol=-19.2`（默认就是这条），`?bgm=0` 关闭。
- ⚠️ **两个 3dB 坑，别再来回改这个数**（v7 排查时来回错了两次）：
  ① `ffmpeg` 的 stereo→mono 在 **s16 与 f32 输出之间差 3.01dB**（同源 mp3：s16 −14.86 / f32 −11.85）。
     `audio-render.mjs` 走 s16 路径 → **拿 f32 解码去量，会把 −18dB 量成 −21dB**，那是尺子差不是工程差；
  ② 垫音去掉 `air` 层后，"峰值归一化到 −1dBFS"会整体抬高 1.17dB（旧素材的峰值被噪声顶高了）。
  两者相抵后推子写 **−19.2dB**，成片电平与 v6/v7 原档一致（bed 53.8Hz 差 ≤0.25dB）。
- 成片：离线混音时同一条总线（`tools/audio-render.mjs` 会把 BGM 作为 bed 叠进去）。
- 避雷：BGM 绝不能是强节奏纯音乐，翻车案例基本都是 BGM 抢了画面叙事。

### 6.6 素材挑选要点（给你选授权 WAV 时用）

| 文件 | 检索词（英文优先） | 筛选标准 |
| --- | --- | --- |
| `soft_tick` | minimal glass tap / soft glass tick / hollow tap short | 短、干净、**偏闷的玻璃轻触**，不要清脆叮咚铃音 |
| `swish_soft` | soft swish / minimal whoosh light / air sweep subtle | 慢、气流感，不是快速呼啸，无强风声噪 |
| `low_impact` | minimal low impact short / sub bass hit / soft stinger low thud | 低频扎实、衰减极快，不要爆破音、不要长混响 |
| `pulse_tap` | tonal pulse short / subtle resonant tap | 带一点柔和共鸣，像微小球体震动，不是电子哔声 |
| `sub_rise` | minimal rise fx slow / subtle pitch swell short | 平缓柔和爬升，不尖锐，不要惊悚悬疑感 |
| `ambient_pad` | minimal ambient underscore slow no drums / cerebral ambient pad | 无鼓点、暗调、长音垫；**无嘶声、无次声摆动**（选完跑 §6.9 量测） |

**避雷词**：epic / trailer / explosion / cartoon / ding / bell / sparkle / boom / loud / fantasy。
**挑选实操**：波形尾部快速归零（拖尾短）→ 叠上 BGM 不抢戏 → 优先 44.1kHz 16bit（单声道够用）→
同类下 2–3 个备选，在 S2 原型里对比锁定，其余丢弃。**版权**：优先 Zapsplat / Epidemic /
Uppbeat / PremiumBeat 等授权库；免费库务必看清 CC 协议可商用。

> 结论：成片按 §6.1 原则交付 **无人声**。本节记录旁白流水线的做法（含脚本与时间码），
> 需要时可用 `tools/narration.mjs` 重新挂上，不会影响画面。

**定位**：作为可选的叠加听觉引导层 —— 画面（文案 100% 在屏上）本身已能独立看懂，
旁白只是引导；加或去掉都不影响叙事完整。

| 项 | 规格 |
| --- | --- |
| 文案 | 原稿 32 句、一字不改，按画面分片时刻对齐（时刻从 `__pieces()` 取，与画面同源） |
| 落点 | 每条旁白从「该句在画面上出现」的时刻起念；若与前一条挤在一起，顺延并留 0.12s 气口 |
| 语速 | 按屏拟合：先按 rate 0 合成，超窗口就逐级提速；允许旁白"溢"过换屏点 2.5s（连续语流不必卡死在屏内） |
| 电平 | 旁白峰值 **−3dBFS**；旁白出现时垫音（BGM+foley）**下压最多 −8dB**（起音/释放各做了包络平滑） |
| 成片电平 | 混合峰值 −3.0dBFS，无削波 |
| 实现 | `tools/narration.mjs`：TTS(Windows 本地) → 时长拟合 → 排布 → 与 foley/BGM 混音 → 输出音轨 + 脚本 + SRT |

**旁白是可替换的临时配音**：脚本里用 Windows 本地 TTS（`Microsoft Huihui Desktop`，zh-CN）生成，
目的是把**时间轴和电平**先定死。真人录音替换有两条路：

1. 直接替换音轨：录一条 150.000s 的旁白 → 覆盖 `qa/v2/v33/旁白-150s.wav` →
   `node narration.mjs --bed <foley+bgm.wav>` 重混 → 重新合轨（画面不用重渲）；
2. 按谱配音：`qa/v2/v33/旁白脚本-时间码.md`（画面时刻 / 落点 / 语速 / 文案）与
   `qa/v2/v33/旁白-150s.srt` 直接给配音员或剪映。

> 屏内语速参考：S1 rate 3、S2 rate 2、S5 rate 1、S3/S4/S6/S7 rate 0（正常语速）。
> 想更从容就把 `narration.mjs` 里 `scr.t1 + 2.5` 的溢出量调大（代价是旁白更"追不上"画面）。

### 6.9 噪检判据（v7 起执行，写死）

**① 先分清"文件自带"还是"本地监听"**（这一步最容易判反）：
把导出文件拷到手机 / 另一台设备戴耳机听。**高频嘶声手机能听见，低频嗡声手机听不见**——
所以"手机听不到"**不等于**"是电脑接地干扰"。只有**手机也没有嘶声**才算真干净；
手机也听得见 = 音频素材 / 混音 / 编码的问题，必须改工程。

**② 量测口径：汉宁窗逐帧频谱，禁用"整段 FFT 高通后算 RMS"**

```powershell
cd tools
node noise-floor.mjs "..\qa\v2\v7\bed-128s.wav"            # 186ms 帧 / 50% 重叠 / 取帧间中位数
node noise-floor.mjs "..\qa\v2\v7\control-illusion-v7-128s-带音效-抬高11dB.mp4"
```

⚠️ 整段 FFT 的坑：40–80Hz 的强音会向高频泄漏，能把一条 **−132dBFS** 的干净音轨量成 **−72dBFS**（v7 排查时踩过）。

| 量测项（帧中位） | 阈值 | v7 实测（抬高 11dB 母版） |
| --- | --- | --- |
| 1–4kHz | ≤ −95 dBFS | **−121.4** ✅ |
| 4–8kHz | ≤ −100 dBFS | **−121.5** ✅ |
| 8–16kHz | ≤ −100 dBFS | **−121.5** ✅ |
| 总 RMS | —— | −24.4 dBFS（母版 −27.0 LUFS / 真峰 −1.0 dBTP） |

**③ 定位顺序**（10 分钟）：单独播垫音 → 全轨 −6dB 预览（查是否叠加过载）→ 导纯音频 WAV 对比成品
（分编码噪声）→ 换设备复听（分本地监听）。

### 13.8 v7 音频缺陷修复（2026-10-08 · 替换交付物）

**现象**：成片全程有一层不随画面变化的持续底噪（"滋滋 + 嗯嗯"），连静音留白段也在；手机播放同样能听见。

**根因**（样本级定位，不是"疑似"）：占位垫音 `v2/audio/ambient_pad.mp3` 的合成器，在四声部之上加了一层 `air` 白噪：

```js
airL = 0.995 * airL + 0.005 * (rnd() - 0.5);     // 白噪 → 漏积分
L[i] = (sL + airL * 3.2) * breath * 0.5;         // 再乘 3.2 混进垫音
```

0.995 的漏积分只有 **6dB/oct**，对 1kHz 以上只衰减约 −46dB —— 于是它同时留下
① 1kHz 以上的**宽带嘶声**（"滋滋"）② 5–35Hz 的**次声摆动**（"嗯嗯"，还会吃掉动态余量）。
用同一段合成器逻辑离线复现，>1kHz 得 −42.98dBFS，与垫音实测 −43.18dBFS 逐位吻合（旧尺子口径）。

**排除**：AAC 192k 编码（母版 vs bed 逐频段只差 +0.08dB，>8kHz +0.4dB，基本透明）；
削波（bed 峰值 −11.4dBFS，全程无削平样本）；事件音效（`pulse_tap` −63dB、`low_impact` −67dB、
`sub_rise` −101dB 于 >1kHz）；市电 50Hz 工频（成品 49.8Hz 处 −51.4dBFS，比邻域低 2.5dB，**无工频线**）。
垫音里那条 53.8Hz 是四声部的 A1# 低音根音（比邻域高 24dB，是音乐音高不是工频），**保留**。

**修法**：`tools/make-foley.mjs` 第 7 段删掉 `airL/airR` 两行与 `airL * 3.2` 项；归一化前对 L/R
各串一次**二阶巴特沃斯高通 @20Hz**（12dB/oct）。**不**再补噪声层——呼吸感由 `breath` 振幅调制负责，
加噪声等于把刚清掉的嘶声用更贵的方式请回来。

> 滤波器选型踩过的坑（第一版已废弃）：最初按"两次一阶 @30Hz"实现，但串联一阶在 **54Hz 处也衰减 −2.33dB**
> （实测根音 −2.50dB），把垫音根音削薄。二阶巴特沃斯 @20Hz 在 54Hz 处只有 **−0.08dB**，
> 四声部相对平衡与原档差 ≤0.2dB（原档 2.90 / 7.07 / 14.37dB ↔ 新版 2.72 / 7.07 / 14.46dB）。
